      Konfiguration

      Änderungen leeren das Spiel. Mit dem Startknopf neu beginnen.

      Score = (schwarz, weiss)

      Schwarz

      Richtige Farbe an der richtigen Position.

      Weiss

      Richtige Farbe, aber an einer anderen Position.

      Die kleinen Pins sind keinen einzelnen Positionen zugeordnet. Jede Farbe im Code wird höchstens einmal pro Vorkommen gezählt.

      Code
      Geheime Farbfolge des Codemakers.
      Guess
      Farbfolge, die der Codebreaker tatsächlich abgibt.
      Testguess
      Farbfolge, die der Algorithmus vor einem Guess untersucht.
      Score
      Bewertung durch den Codemaker: (schwarz, weiss).

      Computer / Codebreaker verwendet Knuths Minimax-Strategie. Im Standardspiel (4 Positionen, 6 Farben, mit Wiederholungen) genügen höchstens 5 Guesses.

      Knuth-Explorer

      ?
      U = alle zulässigen Codes
S = U; G = U
Guess = 1122 im Standardspiel, sonst wähleGuess(S, G)

wiederhole:
  Guess abgeben; Score vom Codemaker erhalten
  G = G ohne Guess
  S = {Code in S: score(Code, Guess) = Score}
  falls S leer: widersprüchlichen Score melden; abbrechen
  falls Score = (Anzahl Positionen, 0): fertig
  Guess = wähleGuess(S, G)

wähleGuess(S, G):
  falls |S| = 1: einziger Code aus S
  für jeden Testguess in G:
    gruppiere alle Codes aus S nach score(Code, Testguess)
    minel[Testguess] = |S| - Grösse der grössten Gruppe
  wähle Testguess mit grösstem minel
  bei Gleichstand: Code in S bevorzugen, dann kleinster Code
